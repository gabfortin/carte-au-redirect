# carte-au-redirect

Redirige `carte-au.gabfortin.com` vers [montrealaccessible.ca](https://montrealaccessible.ca), en conservant le chemin, les paramètres et l'ancre (ex. `?arrondissement=`).

GitHub Pages n'accepte qu'un domaine personnalisé par dépôt : ce dépôt sert uniquement l'ancien domaine, et `carte-au` sert `montrealaccessible.ca`. `404.html` est une copie de `index.html` pour que toute URL (ex. `/confidentialite.html`) soit aussi redirigée.
